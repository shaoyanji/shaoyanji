# shaoyanji

[![shaoyanji](https://res.cloudinary.com/de1eajx01/image/upload/f_auto,q_auto,w_1200/assets/repos/shaoyanji)](https://github.com/shaoyanji)

I build systems that hold their own state: one Nix flake for a fleet of NixOS and Darwin hosts, thin Go services with immutable records, and research on streaming state machines. Self-hosted, offline-first, and readable from a terminal.

<p><img align="center" src="https://github-readme-stats.zohan.tech/api?username=shaoyanji&show_icons=true&locale=en&theme=tokyonight&hide_border=true&count_private=true" alt="shaoyanji on GitHub" /></p>

## Building

| Repo | What it is |
| :--- | :--- |
| [`nixconfig`](https://github.com/shaoyanji/nixconfig) | One flake for NixOS, nix-darwin, Home Manager and WSL; hosts, modules, tasks and docs from a single inventory. |
| [`bountystash`](https://github.com/shaoyanji/bountystash) | Thin server-rendered Go app that turns messy asks into immutable, hash-stable work packets. |
| [`pancakes-harness`](https://github.com/shaoyanji/pancakes-harness) | Local-first context and egress kernel; typed ingress, replayable consult records, bounded packets. |
| [`fibtransponder`](https://github.com/shaoyanji/fibtransponder) | Fibonacci-radix streaming state machine, tested as a tokenization substrate rather than a product. |
